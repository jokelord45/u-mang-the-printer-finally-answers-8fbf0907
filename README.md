## The task

Write the one line, 1 to 240 characters, the office printer would finally say
back to everyone staring at it: the paper jams, the cryptic error codes, the
thumps when it stops working. Funny, in the printer's own voice, landing its
comeback in a single read.

## The entry

> Eleven years I've said PC LOAD LETTER and I still don't know what it means — but sure, thump me again, that always fixes it.

The machine confesses it never understood its own error code in eleven years
of printing it — then turns the thump back on the human with a straight face.
Weary, literal, and faintly passive-aggressive, exactly how a printer that
has counted every sheet would answer.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (124 characters, one sentence).
